## 🚀 Quick Start (Run Any Project)

Every project folder contains a one-click **`run.bat`** script and pre-compiled classes in `out/`:

- **Task 1:** `cd Java-Task1-OnlineReservationSystem && .\run.bat`
- **Task 2:** `cd Java-Task2-NumberGuessingGame && .\run.bat`
- **Task 3:** `cd Java-Task3-ATMInterface && .\run.bat`
- **Task 4:** `cd Java-Task4-OnlineExaminationSystem && .\run.bat`
- **Task 5:** `cd Java-Task5-DigitalLibraryManagementSystem && .\run.bat` *(Opens `http://localhost:8085`)*
